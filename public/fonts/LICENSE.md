The Neue Montreal font files in this directory are used under Pangram Pangram
Foundry's trial license, which permits personal and portfolio use.

- `NeueMontreal-Regular.otf` (weight 400) — primary body weight
- `NeueMontreal-Medium.otf` (weight 500) — emphasis / title weight
- Additional weights (Light / Bold / Italic variants) — included from the
  trial pack but not actively referenced in the current type scale
